## 예제 문제

> **"계단을 오르는 방법의 수를 반환하라"**
> 한 번에 1칸 또는 2칸씩 오를 수 있을 때, n개의 계단을 오르는 방법은 몇 가지인가?

```
n = 4 → 5
```

---

## 1단계 — 손으로 작은 값부터 써보기

DP는 처음부터 떠올리는 게 아니라, **직접 써보면서 패턴을 발견하는 거예요.**

```
n=1: [1]                          → 1가지
n=2: [1+1], [2]                   → 2가지
n=3: [1+1+1], [1+2], [2+1]        → 3가지
n=4: [1+1+1+1], [1+1+2], [1+2+1],
     [2+1+1], [2+2]               → 5가지
```

---

## 2단계 — 패턴 발견

```
n=1 → 1
n=2 → 2
n=3 → 3   ← 1+2
n=4 → 5   ← 2+3
n=5 → 8   ← 3+5
```

> **"현재 값 = 직전 값 + 직직전 값"**

---

## 3단계 — 왜 이 패턴인가?

문제 조건을 **거꾸로** 생각하면 나와요:

> **"n번째 계단에 도착하기 직전에 어디 있었을까?"**

```
1칸씩 오를 수 있으니까  → 직전에 (n-1)번째 계단에 있었거나
2칸씩 오를 수 있으니까  → 직전에 (n-2)번째 계단에 있었거나
```

딱 두 가지 경우밖에 없어요:

```
n번째 방법의 수 = (n-1)번째 방법의 수 + (n-2)번째 방법의 수
```

---

## DP란?

> **"이미 계산한 결과를 저장해두고 재사용하는 것"**

```
DP 없이:
  n=5 계산 → n=4 계산 → n=3 계산 → ...
             n=3 계산  ← 또 계산!
             n=2 계산  ← 또 계산!

DP 있이:
  n=1 → 1  저장
  n=2 → 2  저장
  n=3 → 3  저장  (n=1, n=2 재사용)
  n=4 → 5  저장  (n=2, n=3 재사용)
```

---

## DP를 선택하는 신호

```
"이전 결과를 재사용할 수 있는가?"  → DP
"경우의 수를 구하는가?"            → DP
"최솟값/최댓값을 구하는가?"        → DP
```

---

## DP가 처음에 어려운 이유

```
보통 사고:   앞에서 → 뒤로  "어떻게 올라가지?"
DP 사고:     뒤에서 → 앞으로 "도착하기 직전에 어디 있었지?"
```

평소 사고 방향과 반대라서 낯설어요.

> **DP는 패턴을 써보면서 발견하는 거예요. 답을 보고 "아, 이런 패턴이구나" 를 반복하다 보면 자연스럽게 보이기 시작해요.**

---

## 4단계 — 로직을 쓰다가 변수 발견

```
n=1 의 값을 기억해야 하네  → prev2 = 1  (직직전 값)
n=2 의 값을 기억해야 하네  → prev1 = 2  (직전 값)
현재 값을 계산해야 하네    → current = prev1 + prev2
계산 후 한 칸씩 이동해야 하네
```

---

## 5단계 — 이동 규칙

```
이동 전:
직직전(prev2)=1  직전(prev1)=2  현재(current)=3

이동 후:
직직전(prev2)=2  직전(prev1)=3
     ↑                ↑
  prev1 이었던 것   current 였던 것
```

코드로:

```python
current = prev1 + prev2   # 현재 = 직전 + 직직전
prev2 = prev1             # 직직전 ← 직전
prev1 = current           # 직전 ← 현재
```

---

## 6단계 — 완성 코드

```python
def climb_stairs(n):

    # 엣지케이스
    if n == 1:
        return 1

    prev2 = 1   # n=1 의 값 (직직전)
    prev1 = 2   # n=2 의 값 (직전)

    for i in range(3, n+1):         # 3부터 n까지
        current = prev1 + prev2     # 현재 = 직전 + 직직전
        prev2 = prev1               # 직직전 ← 직전
        prev1 = current             # 직전 ← 현재

    return prev1
```

---

## 7단계 — 머릿속 추적

```
n=4

prev2=1, prev1=2

i=3: current=2+1=3, prev2=2, prev1=3
i=4: current=3+2=5, prev2=3, prev1=5

→ return 5  ✓
```

---

## 시간복잡도 & 공간복잡도

```
시간복잡도: O(n)   → n번 반복
공간복잡도: O(1)   → prev1, prev2, current 변수 3개만 사용
```

## 사고 흐름 요약

```
손으로 작은 값부터 써보기
        ↓
숫자 사이의 패턴 발견
        ↓
"도착하기 직전에 어디 있었지?" 역방향 사고
        ↓
이전 결과 재사용 → DP 선택
        ↓
로직을 쓰다가 → prev1, prev2 변수 발견
        ↓
이동 규칙 → prev2 = prev1, prev1 = current
        ↓
완성 → O(n), O(1)
```

> **DP는 처음부터 떠올리는 게 아니라, 작은 값부터 직접 써보면서 패턴을 발견하는 거예요.**
> **"이전 결과를 재사용하는가?" 가 보이면 DP를 선택하세요.**
