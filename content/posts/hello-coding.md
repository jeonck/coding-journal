## 블로그를 시작하며

코딩을 익히는 가장 좋은 방법 중 하나는 **직접 써보고 설명하는 것**입니다.  
이 블로그에서는 각 토픽마다 실제 예시 코드를 포함한 글을 한 편씩 작성할 예정입니다.

## 앞으로 다룰 내용

- 파이썬 기초부터 응용까지
- 알고리즘과 자료구조
- 웹 개발 (HTML, CSS, JavaScript)
- 도구 사용법 (Git, CLI 등)

## 예시: Hello, World!

```python
# 가장 간단한 파이썬 코드
print("Hello, Coding Journal!")
```

앞으로 이런 식으로 코드 예시와 함께 개념을 설명해 나가겠습니다.
