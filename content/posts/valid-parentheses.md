## 예제 문제

> **"괄호로 이루어진 문자열이 유효한지 확인하라"**

```
"(())"  → True
"(]"    → False
"([)]"  → False
```

---

## 1단계 — 입출력 계약

```
입력: 괄호 문자열 "(())"
출력: 유효하면 True, 아니면 False
```

함수 뼈대:

```python
def is_valid(s):

    return
```

---

## 2단계 — 손으로 풀기

`"(())"` 를 손으로 확인한다면?

```
( → 열림
( → 열림
) → 가장 최근에 열린 ( 와 짝
) → 가장 최근에 열린 ( 와 짝
→ 다 짝이 맞음 → True
```

핵심 패턴:

> **"가장 최근에 열린 것과 짝을 맞춘다"**

---

## 3단계 — 자료구조 선택

### 스택

"가장 최근에 열린 것" 을 기억하려면 **스택** 이 필요해요.

Python에서 스택은 리스트로 구현해요:

```python
stack = []

stack.append("(")  # 추가 → ["("]
stack.append("(")  # 추가 → ["(", "("]
stack.pop()        # 꺼냄 → ["("]
stack.pop()        # 꺼냄 → []
```

스택에서 꺼낼 때는 **가장 마지막에 넣은 것** 이 나와요.

### 딕셔너리

닫힌 괄호가 나왔을 때, 스택에서 꺼낸 것과 **짝이 맞는지 확인** 해야 해요.

이 짝 정보를 딕셔너리로 관리해요:

```python
pairs = { ")": "(", "]": "[", "}": "{" }
#          ↑            ↑
#        닫힌괄호 : 짝이되는 열린괄호
```

> **두 정보를 연결해서 기억해야 할 때 → 딕셔너리**

---

## 4단계 — 코드 흐름 (주석 먼저)

```python
def is_valid(s):

    stack = []
    pairs = { ")": "(", "]": "[", "}": "{" }

    for char in s:
        # 열린 괄호면 → 스택에 추가
        # 닫힌 괄호면 → 스택에서 꺼내서 짝이 맞는지 확인
        #              짝이 안 맞으면 → 바로 False

    # 스택이 비었으면 True, 남아있으면 False
    return
```

---

## 5단계 — 완성 코드

```python
def is_valid(s):

    stack = []
    pairs = { ")": "(", "]": "[", "}": "{" }

    for char in s:
        if char in ["(", "[", "{"]:
            stack.append(char)       # 열린 괄호면 스택에 추가
        else:
            top = stack.pop()        # 스택에서 꺼내서 top에 저장
            if top != pairs[char]:   # 짝이 안 맞으면
                return False         # 바로 False

    return len(stack) == 0           # 스택이 비었으면 True
```

---

## 6단계 — 머릿속 추적

```
"([)]"
( → stack = ["("]
[ → stack = ["(", "["]
) → top = "[",  pairs[")"] = "("  →  "[" != "("  → False ✓

"([])"
( → stack = ["("]
[ → stack = ["(", "["]
] → top = "[",  pairs["]"] = "["  →  "[" == "["  → 계속
) → top = "(",  pairs[")"] = "("  →  "(" == "("  → 계속
→ len(stack) == 0 → True ✓
```

---

## 코드 핵심 포인트

**`stack = []`**  
열린 괄호를 담아둘 리스트. 스택은 Python에서 리스트로 구현.

**`stack.append(char)`**  
열린 괄호를 스택에 추가.

**`top = stack.pop()`**  
스택에서 마지막 것을 꺼내서 top에 저장. 꺼낸 직후 짝이 맞는지 확인하기 위해 변수에 저장.

**`pairs = { ")": "(", ... }`**  
닫힌괄호(key) : 짝이 되는 열린괄호(value) 를 딕셔너리로 관리.

**`len(stack) == 0`**  
스택이 비었으면 True, 남아있으면 False.
